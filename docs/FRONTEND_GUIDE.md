# Rust 桌面与 Web UI 开发规范

> 更新日期：2026-09-09。替代旧 React/Vite 实施指南；网格实验台已实现，真实业务闭环尚未接入。

## 技术与组件

全部新 UI 采用 Rust 1.98.1、Edition 2024、eframe/egui + wgpu。原生桌面和 WASM Web 共用界面、网格、状态机及业务页面；网络、认证、文件、剪贴板、存储、打印与生命周期经宿主适配。详细类型、目录、双端边界与验收见 [组件库规范](UI_COMPONENT_LIBRARY.md)，进度见 [路线图](ROADMAP.md)。

当前先打磨独立网格实验台，以商品、订单、库存结构验证交互与性能，再接商品查询—编辑—保存真实闭环。旧 React 页面冻结作业务参考，无用户不要求逐页复刻。实验台使用同一生产组件，五类组件随真实流程建设。

## Rust 与格式规范

- 根 rust-toolchain.toml 固定 1.98.1，workspace 使用 edition 2024、resolver 3、rust-version 1.98.1；子 crate 继承，rustfmt 显式 edition/style_edition 2024。
- 版本来自 2026-09-09 核实的 [官方 stable 清单](https://static.rust-lang.org/dist/channel-rust-stable.toml)，清单日期 2026-09-03。后续新 stable 单独升级验证，不浮动追踪。
- 遵循 [官方 Style Guide](https://doc.rust-lang.org/style-guide/) 与 [Style Edition](https://doc.rust-lang.org/edition-guide/rust-2024/rustfmt-style-edition.html)，不使用 nightly 格式配置。编辑器调用项目工具链 rustfmt，检查为 `cargo fmt --all -- --check`。
- 局部改动只格式化受影响文件，全仓格式迁移独立实施；Clippy 对受影响包和 native/wasm 目标分别执行，warnings 为错误，不全局压制 lint。
- 可恢复错误使用 Result，类型化 ID/状态与明确所有权；unsafe 说明必要性、安全不变量和测试。UI 不阻塞 I/O，不每帧全量排序；后台任务有取消、代次、有界队列和迟到结果过滤。
- 构建先遵守上级固定缓存、锁与统一入口约束。现有入口缺守护时先补入口，不绕过守护或另建无限 target。

## 工作台与验收

中文术语一致；查询和动作在顶部，主区 DataGrid，详情/子表按实际流程放侧边或底部。活动行、焦点和勾选独立。编辑有草稿、校验、提交、冲突、未知状态；主动离开先处理草稿，权限失效立即隔离。

核心状态机用 Rust 测试；egui 输入帧验证交互；两端实测 IME、冻结列、键盘、粘贴与 DPI。Web 不能只截图 canvas 当作功能通过。真实登录、查询、编辑、保存、失败和重连两端分别验收。打印须有实际设备输出，返回 HTML/PDF 不是已打印。

## UI 呈现与操作效率

- 全部新 UI 禁止说明性副标签、副标题、页面介绍和常驻功能说明；不预留说明占位。必要帮助附在对应控件的鼠标悬停提示中。
- 字段名称、必要单位、真实操作结果、加载状态和校验错误属于操作信息；保持紧凑可识别，详情可悬停查看，不用说明段落挤占业务区域。
- 快速搜索行默认展开，修改条件后自动查询（250 毫秒防抖）；输入法组合过程中不查询，提交后按最终文本查询。不要求点击“应用搜索”。
- 金额范围直接在搜索行展示两个可输入框，中间使用 `-`，不得要求先打开对话框；空边界不限，非法或倒置范围保留输入并标记错误。
- 新输入立即取消旧查询任务，防止旧结果覆盖；等待、查询中及条件无效时禁止基于旧结果发起批量操作。折叠保留条件，重置立即清空并查询。
