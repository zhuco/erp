# 前后端使用方式（Windows / PowerShell）

本文面向本仓库的本地开发与联调，重点说明前端、后端分别如何启动，以及如何进行前后端联调。

## 1. 前置依赖

- Docker Desktop（建议启用 WSL2）
- Rust stable（建议 `1.78+`）
- Node.js 20.x（含 Corepack）
- pnpm（通过 `corepack enable` 启用）
- 可选：`sqlx-cli`（用于手动执行数据库迁移）

## 2. 端口约定

| 服务 | 默认端口 | 说明 |
| --- | --- | --- |
| Web UI（Vite） | 5173 | 前端开发服务 |
| erp-api | 8080 | 后端 API |
| erp-channel | 8081 | Webhook 入站服务 |
| Postgres | 5432 | 数据库 |
| Redis | 6379 | 缓存 |
| NATS | 4222 | 消息总线 |
| NATS Monitor | 8222 | NATS 监控端口 |

## 3. 前端使用方式

### 3.1 仅前端开发（Mock 模式，推荐前端单独开发时使用）

后端服务可不启动，前端通过 mock 数据工作。

#### 一键启动

```powershell
.\scripts\dev-mocks.ps1
```

#### 手动启动

```powershell
corepack enable
pnpm install

$env:VITE_USE_MOCKS="true"
$env:VITE_API_BASE_URL="http://localhost:8080"

pnpm --filter erp-web dev
```

打开浏览器访问 `http://localhost:5173`。

### 3.2 前端接真实后端（联调模式）

```powershell
corepack enable
pnpm install

$env:VITE_USE_MOCKS="false"
$env:VITE_API_BASE_URL="http://localhost:8080"

pnpm --filter erp-web dev
```

## 4. 后端使用方式

### 4.1 准备环境变量

```powershell
Copy-Item env/.env.example .env
```

按需修改 `.env`，至少确认以下配置可用：

- `DATABASE_URL`
- `REDIS_URL`
- `NATS_URL`
- `JWT_SECRET`

### 4.2 启动基础设施

```powershell
docker compose -f docker-compose.local.yml up -d
```

### 4.3 初始化数据库（首次运行建议执行）

```powershell
cargo install sqlx-cli --no-default-features --features rustls,postgres
sqlx migrate run
```

### 4.4 启动后端服务

建议分别打开 4 个终端：

```powershell
cargo run -p erp-api
```

```powershell
cargo run -p erp-channel
```

```powershell
cargo run -p erp-dispatcher
```

```powershell
cargo run -p erp-worker
```

### 4.5 健康检查

- API: `http://localhost:8080/healthz`
- Channel: `http://localhost:8081/healthz`

## 5. 前后端联调建议流程

1. 启动 Docker 依赖（Postgres/Redis/NATS）。
2. 确认迁移已执行（`sqlx migrate run`）。
3. 启动后端四个服务（`erp-api`、`erp-channel`、`erp-dispatcher`、`erp-worker`）。
4. 启动前端并设置 `VITE_USE_MOCKS=false`。
5. 打开 `http://localhost:5173` 进行联调。

## 6. 常用质量门禁命令

统一从仓库根目录执行：

```powershell
pnpm run repo:verify
pnpm run accept:web
pnpm run accept:backend
pnpm run accept:all
```

## 7. 停止与清理

### 7.1 停止开发脚本启动的服务

```powershell
.\scripts\stop.ps1
```

### 7.2 停止 Docker 依赖

```powershell
docker compose -f docker-compose.local.yml down
```

如需清理卷数据（会删除本地数据库数据）：

```powershell
docker compose -f docker-compose.local.yml down -v
```

## 8. 常见问题排查

- `pnpm` 不可用：执行 `corepack enable`，必要时 `corepack prepare pnpm@9.1.0 --activate`
- 5173/8080/8081 端口占用：`Get-NetTCPConnection -LocalPort 5173,8080,8081`
- Docker 启动失败：检查 Docker Desktop 是否运行
- 数据库迁移失败：检查 `.env` 的 `DATABASE_URL` 与 Postgres 容器健康状态
- 前端请求失败：确认 `VITE_API_BASE_URL` 指向 `http://localhost:8080`，并确保 `erp-api` 正常运行
