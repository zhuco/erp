# 正式 ERP UI 接入

独立入口：桌面 `erp-grid-lab --erp`，Web `?erp`。无参数保留组件实验台。

应用外壳 `erp_app` 持有每个页面实例，`workspace_shell` 只管理有界单例标签与导航，不拥有业务数据。商品和订单分别保留查询、分页、勾选、编辑；关闭有草稿页面由目标页保存/放弃契约处理。关闭应用汇总草稿。主表及SKU继续走原有真实API及DataGrid，右侧编辑沿用版本回执。

视觉依据：`qa/legacy-web-retirement/source.zip` 中 `src/styles/theme.css`、`src/app/layout/workbenchPanelSizing.ts` 和 `workbenchLayout.css`；只读取参数，不恢复旧引擎。正文12.8，标题15，页面#f5f7fa、面板白、主色#1f3a5f；左侧240、右侧360、底部280；旧表头24、数据行21。`erp_theme.rs`集中应用主题，网格密度保留实验台默认并允许正式宿主配置。布局比例依宿主可用尺寸收缩。

已完成首个正式宿主：双端 Release 构建、双端 Clippy、受影响测试，以及本地 QA 商品查询/编辑保存回读。Web 已检查旧版浅色紧凑布局，桌面操作及服务端回读成功，但自动截图出现白色客户区，尚不能据此声明桌面视觉验收。详细边界见 qa/acceptance/RESULTS.md。预览页面包含的夹具不是正式报表/仓库业务；部分操作文案仍待统一中文。

## 2026-09-11 工作台结构落地

- 新顶部注册表统一货品、销售及开发工具入口，支持功能搜索；未接入的旧业务模块不生成空页面。注册表权限字段是元数据，不能冒称前端权限过滤已替代服务端授权。
- 标签支持水平滚动、Ctrl+Tab/反向切换、右键刷新/关闭当前/其他/全部；批量关闭逐页等待脏页决定。标签及面板偏好按已认证服务/商户/操作者及页面隔离，稳定页面名不依赖中文标题。
- 商品左侧分类调用原有完整远端选项，主表/SKU/右编辑保持原保存契约；订单左侧订单号/平台/状态过滤接入现有服务端查询，右侧显示已加载订单真实状态/版本，底部货品独立高度。桌面Windows正式入口默认DX12+AutoVsync，环境变量仍能覆盖后端；Lab性能模式保留原设置。
- 只接入已有货品及订单宿主，不代表旧菜单全部业务已实现；报表/仓库夹具仍归开发工具。部分操作文案保留原英文，未扩大到完整本地化或SaaS。
