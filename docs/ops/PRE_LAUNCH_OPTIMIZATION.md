# 上线前优化与待完成清单

本文用于上线前的功能补齐与质量优化，结合现有能力与缺口矩阵进行落地检查。

## 一、P0 必须完成（上线门槛）
- [ ] 发货确认闭环：补齐发货确认、失败重试与追踪链路。
- [ ] 退货入库回补库存：售后收货与库存/出库联动，明确入库单与库存流水规则。
- [ ] 支付对账流程：补齐支付账单导入与对账任务，形成对账差异输出。
- [ ] 多包裹/包裹明细：OMS 侧出库包裹信息闭环。
- [ ] 导出任务输出存储：明确导出文件落地路径（对象存储/本地挂载）与过期策略。
- [ ] 监控告警：关键链路（订单投影、出库、发货确认、库存调整）建立仪表盘与告警。
