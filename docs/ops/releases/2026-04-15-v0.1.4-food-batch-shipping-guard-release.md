# ERP Web v0.1.4 发布更新文档

日期：2026-04-15

## 版本信息
- 产品：`erp-web`
- 发布版本：`0.1.4`
- 发布类型：食品批次发货阻断与序列号冲突治理增强版
- 对应分支：`codex/release-gate-hardening-20260414`

## 本次发布目标
- 在工业级电商 ERP 发货主链路补齐食品批次的后端硬阻断能力，避免批次治理只停留在页面层。
- 将序列号冲突诊断与 API 错误语义统一到可运维、可观测、可回归的冲突模型。
- 输出可追溯发布文档与任务证据，支持“提交、合并、推送”收口。

## 本次核心变更

### 1. 食品批次发货阻断后端化（WMS 出库）
- 文件：`crates/erp-repo/src/wms/store.rs`
- 新增规则：
  - 批次商品未完成批次绑定时，禁止发货。
  - 批次 `expire_at <= now` 时，禁止发货。
  - 批次 `production_date > now` 时，禁止发货。
- 错误消息包含 `sku_id`、`batch_no`、`expire_at/production_date` 上下文，便于前端提示与运维定位。

### 2. API 错误语义分级
- 文件：`crates/erp-api/src/lib.rs`
- 新增 `wms_ship_error_response(...)`：
  - 将“发货前序列号/批次约束冲突”统一映射为 `409 conflict`。
  - 保持参数错误类返回 `400`，减少语义混淆。

### 3. 回归测试增强
- 文件：`crates/erp-api/tests/wms_outbound_serials.rs`
- 新增/补强用例：
  - `wms_outbound_ship_blocks_expired_batch`
  - `wms_outbound_ship_blocks_future_production_batch`
  - 序列号占用冲突错误上下文断言增强（`status/ref_doc_type/ref_doc_id`）

### 4. 任务执行与差距评估文档
- 文件：
  - `docs/ops/tasks/2026-04-15/erp95-round14-exec-log.md`
  - `docs/ops/tasks/2026-04-15/erp95-industrial-gap-snapshot.md`
- 更新内容：
  - 补录 Round 14 发货阻断增强与命令证据。
  - 更新工业级差距快照，明确剩余缺口与下一轮优先级。

## 已知环境风险
- Windows 链接阶段偶发 `LNK1318/LNK1140`（PDB 限制），可能导致长链路 `cargo test` 执行超时。
- 已采用容灾措施：清理 `target/debug` 产物、清理残留 `cargo/rustc/link` 进程，并保留可编译验证与历史通过证据。
