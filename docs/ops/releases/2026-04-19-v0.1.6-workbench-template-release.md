# ERP Web v0.1.6 发布更新文档

日期：2026-04-19

## 版本信息
- 产品：`erp-web`
- 发布版本：`0.1.6`
- 发布类型：工作台模板统一与发布守卫增强版
- 对应分支：`codex/release-gate-hardening-20260414`

## 本次发布目标
- 继续把订单、渠道、店铺商品、销售设置等高频页面收敛到统一的工作台模板体系。
- 补齐工作台主表格、左右面板、底部面板之间的组合能力，降低页面实现分叉。
- 将模板治理、Git hooks、UTF-8 编码校验和发布证据文档纳入仓库级发布流程。

## 核心变更概览

### 1. 工作台模板与页面骨架统一
- 新增页面模板与工作台组件族，补齐订单审核、店铺商品、销售设置等场景的页面装配能力。
- `router.tsx`、`WorkbenchLayout`、`RouteTabs`、菜单模型与主表格结构列继续收敛，统一导航、键盘流与布局语义。
- 一批旧版模板组件、占位页和孤立页面实现被删除或替换，减少重复维护面。

### 2. 核心业务页面工业化升级
- 渠道页、店铺商品下载页、销售设置页完成较大规模结构重写，迁移到统一工作台外壳。
- 订单查询、订单审核、订单异常、入库、WMS、商品、打印等页面继续向统一工作台体验靠拢。
- 新增与更新了多组工作台相关单测和 E2E，用于覆盖可见性、键盘流、布局模板与回归场景。

### 3. Mock 数据、主链流程与测试收尾
- 前端路由诊断汇总测试改为使用相对当前时间，避免默认 24 小时窗口导致的空结果误报。
- 工作台命令面板测试同步到当前 i18n 文案实现。
- OMS/WMS mock API 相关测试改为基于当前导出的 special IDs 与主链种子数据断言，避免旧硬编码样本漂移。
- 对较慢的 mock API 单测增加局部超时，解决全量 `vitest --run` 时的误超时问题。
- 后端发布收尾测试修正 `/healthz` 与前端路由诊断烟测的环境敏感断言，兼容数据库未就绪分支。

### 4. 仓库级发布守卫增强
- 新增 `.githooks`、编码校验与修复脚本、页面模板基线检查脚本以及对应计划/规格/运维文档。
- 本次提交按“提交所有未提交更改”执行，包含已修改、已删除与未跟踪文件。
