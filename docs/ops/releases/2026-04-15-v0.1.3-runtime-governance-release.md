# ERP Web v0.1.3 发布开发文档

日期：2026-04-15

## 版本信息
- 产品：`erp-web`
- 发布版本：`0.1.3`
- 发布类型：商品行业化与运行期治理增强版
- 对应分支：`codex/release-gate-hardening-20260414`

## 本次发布目标
- 将工业级电商 ERP 商品主档行业化能力与运行期治理能力形成一条可合并、可推送、可回归的闭环交付。
- 重点补齐三类高价值能力：
  - 食品：保质期、生产日期、批次治理前置阻断
  - 鞋服：尺码颜色规格矩阵与批量派生
  - 数码：序列号策略摘要、运行期推荐前缀、生成阻断

## 关键业务收益
- 食品 SKU 在批次页可直接看到治理规则，并在保存前得到可见阻断原因，减少漏填失效日期。
- 数码 SKU 在序列号页可自动带出推荐前缀，减少人工输入成本和误生成风险。
- 商品主档对食品、鞋服、数码三类行业模板的支持更加完整，形成从建档到运行期的可追踪链路。
