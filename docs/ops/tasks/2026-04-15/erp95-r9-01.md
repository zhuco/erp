# ERP95 R9-01 食品批次页治理禁用态与保存前可见原因

- 日期：2026-04-15
- 目标：在 `sku-batches` 页面把食品治理从“保存时报错”前移成“保存前禁用 + 原因可见”。
- 主文件：
  - `apps/erp-web/src/pages/skuBatches/SkuBatchesPage.tsx`
  - `apps/erp-web/e2e/sku-runtime-governance.spec.ts`
- 验证命令：
  - `pnpm --filter erp-web exec playwright test e2e/sku-runtime-governance.spec.ts --project=chromium --grep "食品"`
- 验收标准：
  - 选择 `SKU-FOOD-GOV-001` 后，缺失失效日期时保存按钮禁用。
  - 页面可见明确原因提示，说明食品 SKU 需先填写失效日期。
  - 选择 `SKU-FOOD-NOBATCH-001` 后，保存按钮禁用且提示未启用批次管理。
- 边界：
  - 不下钻 WMS 入库、拣货、波次流程。
  - 不新增后端强校验，只做前台运行期易用性增强。
