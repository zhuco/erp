# ERP95 R8-02 数码序列号治理挂点前台化

- 日期：2026-04-15
- 目标：在 `sku-serials` 页面补齐数码 SKU 的序列号治理提示与生成前校验。
- 主文件：
  - `apps/erp-web/src/pages/skuSerials/SkuSerialsPage.tsx`
  - `apps/erp-web/src/pages/products/productIndustry.ts`
  - `apps/erp-web/e2e/sku-runtime-governance.spec.ts`
- 验证命令：
  - `pnpm --filter erp-web exec playwright test e2e/sku-runtime-governance.spec.ts --project=chromium --grep "数码序列号"`
- 验收标准：
  - 数码治理样本 SKU 打开生成抽屉后可见序列号治理提示。
  - 未启用序列号管理的 SKU 无法生成唯一码。
  - 启用序列号管理的 SKU 可成功生成唯一码。
- 边界：
  - 关键路径不依赖 `sku-serial-rules` 成功返回。
  - 不下钻售后追踪、平台回传与后端唯一校验。
