# ERP95 R10-01 食品批次临期/禁售状态标签前台化

- 日期：2026-04-15
- 目标：在 `sku-batches` 页面把食品批次的临期、禁售、正常三类效期风险直接前台化。
- 主文件：
  - `apps/erp-web/src/pages/skuBatches/SkuBatchesPage.tsx`
  - `apps/erp-web/src/api/mocks/data.ts`
  - `apps/erp-web/e2e/sku-runtime-governance.spec.ts`
- 验证命令：
  - `pnpm --filter erp-web exec playwright test e2e/sku-runtime-governance.spec.ts --project=chromium --grep "临期|禁售"`
- 验收标准：
  - 食品治理样本批次中可稳定看到临期与禁售标签。
  - 状态标签基于失效日期与食品治理参数计算，而不是写死文案。
  - 非食品批次不会错误显示食品效期风险标签。
- 边界：
  - 不新增后端字段。
  - 不改 WMS 入库、出库主链。
