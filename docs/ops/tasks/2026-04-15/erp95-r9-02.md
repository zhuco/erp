# ERP95 R9-02 数码序列号页自动前缀建议与治理禁用态

- 日期：2026-04-15
- 目标：在 `sku-serials` 页面补齐推荐前缀、生成禁用态与阻断原因。
- 主文件：
  - `apps/erp-web/src/pages/skuSerials/SkuSerialsPage.tsx`
  - `apps/erp-web/e2e/sku-runtime-governance.spec.ts`
- 验证命令：
  - `pnpm --filter erp-web exec playwright test e2e/sku-runtime-governance.spec.ts --project=chromium --grep "数码"`
- 验收标准：
  - 选择 `SKU-DIGITAL-GOV-001` 后自动带出推荐前缀。
  - 选择 `SKU-DIGITAL-NOSERIAL-001` 后生成按钮禁用，且原因提示清晰可见。
  - 规则接口失败时，页面仍可依赖推荐前缀完成主流程。
- 边界：
  - 不下钻后端入库唯一校验与出库强绑。
  - 不改打印模板、履约回传等非本轮关键路径。
