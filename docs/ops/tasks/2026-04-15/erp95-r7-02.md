# ERP95 R7-02 鞋服规格生成器合并去重增强

- 日期：2026-04-15
- 目标：让鞋服规格批量生成支持合并已有规格、智能去重，并尽量继承原规格扩展字段。
- 主文件：
  - `apps/erp-web/src/pages/products/productIndustry.ts`
  - `apps/erp-web/src/pages/products/components/ProductApparelSpecComposer.tsx`
  - `apps/erp-web/src/pages/products/productIndustry.test.ts`
- 验证命令：
  - `pnpm --filter erp-web test:unit -- productIndustry.test.ts`
- 验收标准：
  - 再次批量生成时，不会把已有相同颜色/尺码规格重复追加。
  - 已有规格的条码、成本、备注等扩展字段优先保留。
- 边界：
  - 不实现高级三维矩阵。
  - 不改 SKU 独立建档流程。
