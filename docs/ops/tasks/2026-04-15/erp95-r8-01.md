# ERP95 R8-01 食品批次治理挂点前台化

- 日期：2026-04-15
- 目标：在 `sku-batches` 页面补齐食品 SKU 的效期治理提示与前置阻断。
- 主文件：
  - `apps/erp-web/src/pages/skuBatches/SkuBatchesPage.tsx`
  - `apps/erp-web/src/pages/products/productIndustry.ts`
  - `apps/erp-web/e2e/sku-runtime-governance.spec.ts`
- 验证命令：
  - `pnpm --filter erp-web exec playwright test e2e/sku-runtime-governance.spec.ts --project=chromium --grep "食品批次"`
- 验收标准：
  - 食品治理样本 SKU 打开新建批次抽屉后可见食品效期治理提示。
  - 食品 SKU 未填写失效日期时保存失败。
  - 未启用批次管理的 SKU 无法创建批次。
- 边界：
  - 不下钻后端批次强校验。
  - 不改入库、拣货、波次等 WMS 主链。
