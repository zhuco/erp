# 性能基线（Perf Baseline）

## 1. 测试范围

- API：订单、库存、发运、售后、统计
- 前端：关键页面首屏与交互响应
- 异步链路：Webhook -> Outbox -> Worker

## 2. 基线环境

- CPU：8 vCPU
- 内存：16 GB
- Postgres：托管实例（生产同规格）
- NATS：3 节点

## 3. 指标与目标

1. API
- P95 延迟 < 300ms（读）
- P95 延迟 < 500ms（写）
- 错误率 < 0.5%

2. 前端
- 首屏 FCP < 2.5s
- 页面交互反馈 < 200ms

3. 异步
- Outbox 积压 < 1000
- 消费失败重试成功率 > 99%

## 4. 压测场景

1. 订单高峰
- 100 RPS 持续 30 分钟

2. WMS 出库波次
- 并发 200 波次任务，持续 20 分钟

3. 统计查询
- 并发 50 个统计请求，持续 15 分钟

## 5. 结果记录模板

- 日期
- 版本号
- 场景
- 并发/流量
- P50/P95/P99
- 错误率
- 结论（通过/不通过）
- 改进项
