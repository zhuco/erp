# 易格工作台通用模块

## 当前边界

工具栏仅放在主表区域上方，宽度跟随主表；不横跨左右面板，也不在子表重复放置。左侧树、右侧详情、底部子表各自可隐藏/恢复；隐藏保留本页状态和尺寸，不销毁草稿。

当前阶段先完成通用工作台模块和本地示例页，再接入真实业务。工作台由树形左侧、顶部菜单与多标签、工具栏、主表、底部子表和右侧详情组成。`workbench/*` 只包含通用 egui 状态与绘制；`module_demo/*` 只提供本地夹具，不能作为真实 API、保存或业务验收证据。

独立示例入口使用 `?modules` 或桌面 `--ui-modules`。示例动作必须产生可见的本地状态变化；不得把空按钮或远程请求塞进通用模块。

## 模块职责与接口

`workbench::tree` 提供 `TreeNode { id, label, count, children }`、`TreeFilter { expanded, selected }` 和 `TreeFilter::show(ui, nodes) -> Option<String>`。计数由宿主提供，展开状态按稳定节点 ID 保存；show 支持展开折叠、高亮和获得本树焦点后的上下左右/Enter 导航。

`workbench::toolbar` 提供 `ToolbarState { search, left_open, right_open, bottom_open }` 与 `ToolbarState::show(ui, selected_count, dirty) -> Vec<ToolbarEvent>`。事件包括搜索原文变化、重置、刷新、导出选中和三类面板切换。搜索防抖与 IME 处理由宿主负责；dirty 时保护会丢失草稿的动作。

## 状态隔离与宿主接入

宿主持有树、工具栏、主表、子表和详情状态；每个页面实例使用自己的稳定页面 scope，不能覆盖其他页面的展开、选择、查询或面板尺寸。宿主消费事件后负责查询代次、草稿保护、保存回执和错误展示。

后续接入真实页面时，先在实验台验证键盘、筛选、面板切换和 dirty 路径，再接真实服务端分页与保存契约。模块本身不依赖订单、商品或远程 HTTP。

## 其他工作台契约

导航宿主负责顶部模块菜单、分组入口、功能搜索和多标签。菜单只呈现已注册且可访问的模块；标签以页面 ID 区分，切换时保留各自的树筛选、工具栏、表格选择、详情草稿和布局偏好。`?modules` 示例包含两个独立标签实例，二者不得共享可变页面状态。

布局宿主负责把 `left_open`、`right_open`、`bottom_open` 与面板尺寸应用到实际区域，并在分隔条拖动后更新页面偏好。示例布局按 ui-module-demo + 页面 ID 存储；未来真实宿主再补服务、商户和账号 scope。短表保留宿主分配的底部区域。关闭 dirty 标签前由宿主确认；示例没有网络读写任务。真实宿主负责取消读取及处理未完成写入回执。

详情模块只接收宿主提供的当前 RowId、字段模型和编辑动作，负责紧凑字段编辑、校验状态与草稿呈现；它不自行查询或保存。子表模块接收当前主行的稳定 RowId 和子行数据，维护独立选择、查询、分页和编辑状态，主表切换时由宿主决定是否清理或保留草稿。

主表和子表均复用自研 `DataGrid` 及其列、查询、选择、编辑、分页和底栏契约。工作台模块不实现第二套表格，也不依赖 AG Grid、完整第三方表格或业务目录；网格只负责表格交互，导航、面板、标签和页面生命周期由宿主负责。

## 当前代码入口

- `Navigation::show(ui, entries, dirty)` 返回打开、激活和关闭事件；`commit_close(id)` 由宿主在确认后调用。
- `WorkspaceLayout::show(ui, [left, bottom, right], state, draw)` 分配四个区域，通过 `Region` 回调绘制；三个尺寸由每个页面持有。
- `DetailPanel::show(ui, record_id, fields)` 返回保存字段、取消或阻止切换事件；宿主通过 `resolve_save(result)` 回执。失败保留草稿。
- `SubtableTabs::show(ui, entries)` 返回选中子标签 ID；它只维护子标签，具体子表状态由宿主持有。
- `module_demo::Table` 是 120 行本地夹具适配器：全量筛选后分页，再调用 `DataGrid`。它不代表服务端分页实现。

示例修改仅保留在当前运行内存，重载会恢复夹具；布局尺寸单独保存。菜单当前仅有两个有效示例入口，未填充真实 ERP 全部菜单。
