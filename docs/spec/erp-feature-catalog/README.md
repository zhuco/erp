# 商业化ERP功能清单（本地化版本）

本目录基于对竞品在线文档模块与课程主题的梳理，形成去品牌化、可直接落地的ERP功能清单与流程说明。文档按模块拆分，便于研发按功能逐条实现。

## 目录结构
- `00-范围与命名规范.md`：范围边界、去除模块、名称本地化映射。
- `01-销售与订单管理.md`：全渠道订单、审单、拆合单、结算与发票。
- `02-客户关系与会员.md`：客户画像、会员体系、客户服务联动。
- `03-商品与主数据.md`：SPU/SKU、组合套装、多单位与主数据治理。
- `04-采购管理.md`：采购申请、订单、收货、退货与对账。
- `05-仓储与库存.md`：入库/上架、拣货/复核、盘点与库存控制。
- `06-物流与履约.md`：承运商、面单、轨迹、仓配优化与配送安装。
- `07-售后与服务.md`：退换补发、退款拦截、售后质检与SLA。
- `08-计划与补货.md`：销售预测、补货策略、计划闭环。
- `09-财务与管理会计.md`：应收应付、费用分摊、利润核算。
- `10-营销与价格管理.md`：促销策略、赠品、成本分摊。
- `11-研发与质量.md`：新品立项、检验规范与质量追溯。
- `12-人事与组织.md`：组织、人事、薪资与绩效。
- `13-办公与协同.md`：审批流、通知、任务与协作机器人。
- `14-系统与集成.md`：权限、配置、接口与数据同步。
- `15-运营报表与驾驶舱.md`：内置经营报表与管理看板。
- `16-开发协作与前端规范.md`：多AI协作、目录映射与Workbench UI规范。

- 状态机/数据模型以 `docs/spec/` 与 `openapi/` 为权威来源。
