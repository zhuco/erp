# 营销与价格管理

## 模块定位
统一管理促销活动、价格策略与赠品规则，并与订单、库存、财务打通。

## 业务对象/单据
- 促销活动、优惠券、赠品规则
- 渠道价格表、会员价表
- 营销费用与效果统计

## 功能清单与流程
### 1. 价格策略与渠道价表
**适用角色**：营销主管、销售主管  
**流程**：  
1. 维护基础价、渠道价、会员价。  
2. 设置生效时间与适用范围。  
3. 发布后同步至订单与渠道系统。  
**关键规则**：  
- 支持多币种与税含价配置。  
- 价格变更需保留历史版本。  
**输出**：渠道价表。  

### 2. 促销活动配置
**适用角色**：营销主管  
**流程**：  
1. 创建活动（满减、折扣、第二件优惠）。  
2. 设定活动时间、适用品类与库存占用规则。  
3. 上线后自动应用至订单。  
**关键规则**：  
- 支持活动优先级与互斥策略。  
- 促销库存可独立锁定。  
**输出**：促销活动清单。  

### 3. 随机赠品与赠品策略
**适用角色**：营销专员  
**流程**：  
1. 配置赠品池与触发条件。  
2. 订单生成时随机抽取赠品。  
3. 赠品库存占用并随订单出库。  
**关键规则**：  
- 支持赠品概率与库存不足替换。  
- 赠品需独立成本核算。  
**输出**：赠品发放记录。  

### 4. 优惠券与权益包
**适用角色**：营销专员、客户运营专员  
**流程**：  
1. 创建优惠券模板与发放规则。  
2. 绑定会员等级或活动触发。  
3. 使用后回写订单优惠明细。  
**关键规则**：  
- 支持券码核销与使用次数限制。  
- 过期券自动失效。  
**输出**：优惠券发放与核销记录。  

### 5. 促销成本与投放费用管理
**适用角色**：营销主管、财务会计  
**流程**：  
1. 录入投放费用与渠道推广费用。  
2. 按订单/货品分摊营销成本。  
3. 分摊结果同步到利润分析。  
**关键规则**：  
- 支持多维度分摊模型。  
- 费用核算需关联活动编号。  
**输出**：促销成本明细。  

### 6. 活动效果复盘
**适用角色**：营销主管  
**流程**：  
1. 汇总活动销量、转化、毛利。  
2. 对比预算与实际达成。  
3. 输出复盘报告与优化建议。  
**关键规则**：  
- 复盘需关联活动成本与库存消耗。  
- 支持按渠道/品类拆分分析。  
**输出**：活动复盘报告。  

## 对齐与边界说明
**模块边界**：负责价格与促销规则管理，不包含广告投放或用户触达自动化。  
**输入**：商品价格、会员等级、活动配置。  
**输出**：订单优惠明细、赠品占用记录、促销成本分摊。  
**协同模块**：促销计算由 OMS 调用，会员权益由 CRM 提供。  
**验收要点**：促销叠加规则一致、赠品库存不足替换、费用分摊口径稳定。
