# 范围与命名规范

## 竞品模块梳理（提炼自在线文档）
竞品在线文档的课程标签集中在以下模块：销售订单（OMS）、仓储管理（WMS）、客户关系（CRM）、售后服务、货品和商品、库存管理、物流管理（TMS）、采购管理、计划管理、管理会计、营销管理、研发和质量、人事管理、办公管理、主数据维护、系统管理、运营和决策、数据接口相关内容。

课程主题反复出现的业务点包括：采购申请/退货、订单处理、物流异常、配装（配送+安装）、仓配成本优化、销售发票、代销对账、跨境保税、盲盒赠品、物流接口配置、仓储多单位作业等。

## 本项目范围
围绕“商业化ERP”核心链路（供采销存、财务、履约、服务、组织协同）进行本地化设计，保留可直接落地的管理与执行功能，并对竞品独有命名做去品牌化处理。

### 明确不在范围（删除）
- 自建商城/分销商城相关能力（竞品“吉商城”）。
- 自助BI与数据洞察类能力（竞品“数据洞察”、“吉智BI”）。
- 生产计划与车间执行相关能力（竞品“生产管理/MRP”、“智能制造/MES”）。

> 说明：仍保留“内置经营报表与看板”，但不包含自助建模/自定义BI平台能力。

## 文档维护规则
- 本目录是功能范围基线，仅补充澄清与对齐内容。
- 若出现新功能需求，必须先更新本目录并评审后再进入实现。
- 接口与数据变更需同步 `openapi/` 与 `docs/spec/`。

## AI理解指引
- **边界优先**：OMS 负责订单与结算，WMS 负责仓内作业，TMS 负责运单与轨迹，CRM 负责客户与会员，财务负责应收应付与成本。
- **状态对齐**：订单状态参考 `docs/spec/04_order_status_machine.md`，库存台账参考 `docs/spec/inventory_schema.md`。
- **名称一致**：文档内统一使用本地化命名，不再出现竞品品牌名。
