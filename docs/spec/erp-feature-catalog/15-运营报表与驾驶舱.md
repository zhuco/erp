# 运营报表与驾驶舱

## 模块定位
提供内置经营报表与管理看板，聚焦关键指标监控与运营复盘，不包含自助BI建模能力。

## 业务对象/报表
- 经营驾驶舱、订单与履约报表
- 库存周转与缺货报表
- 财务与利润概要报表

## 功能清单与流程
### 1. 经营驾驶舱
**适用角色**：管理层  
**流程**：  
1. 汇总订单、发货、退款、利润等核心指标。  
2. 按组织与渠道筛选查看趋势。  
3. 关键指标异常触发提醒。  
**关键规则**：  
- 指标口径由管理会计模块统一。  
- 看板支持日/周/月维度。  
**输出**：实时经营看板。  

### 2. 订单与履约报表
**适用角色**：销售主管、物流主管  
**流程**：  
1. 统计订单量、发货时效、异常率。  
2. 按渠道/仓库拆分数据。  
3. 输出履约瓶颈与改进建议。  
**关键规则**：  
- 异常指标需关联处理单。  
- 支持导出与定时发送。  
**输出**：履约报表与异常清单。  

### 3. 库存周转与缺货报表
**适用角色**：仓储主管、计划专员  
**流程**：  
1. 统计库存周转天数与滞销清单。  
2. 识别缺货与超储风险。  
3. 触发补货或促销建议。  
**关键规则**：  
- 计算口径与安全库存同步。  
- 支持按品类/仓库维度查看。  
**输出**：周转与缺货报告。  

### 4. 财务与利润概要报表
**适用角色**：财务会计、管理层  
**流程**：  
1. 汇总收入、成本、费用与利润。  
2. 按渠道/品类输出毛利结构。  
3. 对比预算与实际偏差。  
**关键规则**：  
- 与成本核算口径一致。  
- 报表版本需留存。  
**输出**：利润概览报表。  

### 5. 报表权限与订阅
**适用角色**：系统管理员  
**流程**：  
1. 配置报表访问权限与角色范围。  
2. 设置定时订阅与邮件/消息推送。  
3. 订阅结果回执与失败提醒。  
**关键规则**：  
- 报表数据需遵守数据权限。  
- 订阅失败自动重试。  
**输出**：报表订阅日志。  

## 对齐与边界说明
**模块边界**：仅提供内置报表与看板，不包含自助BI建模。  
**输入**：订单、库存、财务与售后数据。  
**输出**：经营看板、标准化报表与订阅推送。  
**协同模块**：报表口径以财务模块为准，数据权限由系统管理控制。  
**验收要点**：口径一致、订阅准确、权限隔离有效。
