# 计划与补货

## 模块定位
通过预测、补货与计划闭环，平衡库存水平与销售需求，降低缺货与积压风险。

## 业务对象/单据
- 需求预测、补货建议
- 采购计划、调拨计划
- 计划执行反馈

## 功能清单与流程
### 1. 销售预测与需求建模
**适用角色**：计划专员、销售主管  
**流程**：  
1. 导入历史销量与促销计划。  
2. 选择预测模型与季节性参数。  
3. 输出预测需求并进入评审。  
**关键规则**：  
- 支持按渠道/地区/品类预测。  
- 异常波动需人工修正。  
**输出**：需求预测结果。  

### 2. 安全库存与补货策略
**适用角色**：计划专员、仓储主管  
**流程**：  
1. 设置安全库存、周转天数与补货周期。  
2. 计算当前库存缺口与补货量。  
3. 生成补货建议清单。  
**关键规则**：  
- 支持按仓库/品类配置不同阈值。  
- 促销品可单独配置补货策略。  
**输出**：补货建议与预警清单。  

### 3. 采购补货计划生成
**适用角色**：采购主管  
**流程**：  
1. 汇总补货建议并按供应商整合。  
2. 生成采购计划并进入审批。  
3. 审批通过后下发采购订单。  
**关键规则**：  
- 支持最小起订量与经济订货量。  
- 交期不足需生成缺货预警。  
**输出**：采购计划与执行清单。  

### 4. 多仓调拨建议
**适用角色**：仓储主管  
**流程**：  
1. 识别仓库间库存不平衡。  
2. 计算调拨方案与物流成本。  
3. 审批后生成调拨任务。  
**关键规则**：  
- 支持同城优先与时效优先策略。  
- 在途库存需纳入可用量计算。  
**输出**：调拨建议与任务单。  

### 5. 促销备货计划
**适用角色**：营销主管、计划专员  
**流程**：  
1. 录入活动时间与预计销量。  
2. 计算活动备货与安全库存。  
3. 生成活动专用补货计划。  
**关键规则**：  
- 活动备货需锁定库存与预算。  
- 活动结束后自动释放剩余库存。  
**输出**：促销备货计划。  

### 6. 计划执行与反馈闭环
**适用角色**：计划专员  
**流程**：  
1. 跟踪采购/调拨执行进度。  
2. 收集异常原因并调整计划。  
3. 形成计划达成率与偏差报告。  
**关键规则**：  
- 偏差超阈值自动触发复盘任务。  
- 计划版本需保留变更记录。  
**输出**：计划达成与偏差分析。  

## 对齐与边界说明
**模块边界**：仅做需求预测、补货与调拨建议，不包含生产排程或制造执行。  
**输入**：历史销量、库存水位、营销计划与销售目标。  
**输出**：补货建议、采购计划、调拨计划与预警。  
**数据对齐**：库存口径参照 `docs/spec/inventory_schema.md`。  
**验收要点**：安全库存触发补货、活动备货与计划达成率统计。
