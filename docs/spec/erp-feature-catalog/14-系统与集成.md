# 系统与集成

## 模块定位
提供组织权限、流程配置、接口与数据同步能力，保障系统安全稳定运行。

## 业务对象/单据
- 用户、角色、权限、数据权限
- 接口配置、任务调度、数据同步日志
- 系统参数、审计日志

## 功能清单与流程
### 1. 用户与角色权限
**适用角色**：系统管理员  
**流程**：  
1. 创建用户并分配岗位与角色。  
2. 配置菜单、操作与数据权限。  
3. 定期审计权限并清理无效账号。  
**关键规则**：  
- 支持多公司/多组织隔离。  
- 权限变更需记录审批。  
**输出**：权限分配清单。  

### 2. 单据编号与流程配置
**适用角色**：系统管理员  
**流程**：  
1. 配置单据编号规则与前缀。  
2. 设定业务流程节点与审批流。  
3. 流程变更后同步至业务模块。  
**关键规则**：  
- 编号需支持多组织独立配置。  
- 流程变更需版本化管理。  
**输出**：流程与编号规则。  

### 3. 自定义字段与表单
**适用角色**：系统管理员、数据管理员  
**流程**：  
1. 定义字段类型、校验规则与显示位置。  
2. 应用到指定单据或主数据。  
3. 发布后自动同步历史数据展示。  
**关键规则**：  
- 自定义字段需支持导入导出。  
- 变更需兼容历史数据。  
**输出**：字段配置清单。  

### 4. 外部系统接口与对接
**适用角色**：系统管理员、IT人员  
**流程**：  
1. 配置电商平台、物流、支付、第三方仓储接口。  
2. 联调测试并启用生产环境。  
3. 监控接口成功率与异常重试。  
**关键规则**：  
- 支持接口限流与熔断策略。  
- 异常需自动告警。  
**输出**：接口运行报告。  

### 5. 数据同步与任务调度
**适用角色**：IT人员  
**流程**：  
1. 定义数据同步任务与频率。  
2. 执行增量或全量同步。  
3. 记录同步日志与失败重试。  
**关键规则**：  
- 支持按表/按接口的同步策略。  
- 同步失败需生成工单。  
**输出**：同步日志与任务状态。  

### 6. 安全审计与日志管理
**适用角色**：系统管理员  
**流程**：  
1. 记录关键操作与登录日志。  
2. 建立异常行为告警规则。  
3. 定期生成审计报告。  
**关键规则**：  
- 支持日志留存周期配置。  
- 支持按用户/模块查询审计记录。  
**输出**：审计报告与告警记录。  

## 对齐与边界说明
**模块边界**：覆盖权限、配置、接口与审计能力，不包含业务逻辑与 BI 数据仓库。  
**输入**：用户/角色配置、外部平台接入需求。  
**输出**：权限策略、接口运行状态、审计与告警记录。  
**协同模块**：接口契约以 `openapi/erp_api_v1.yaml` 为准，平台适配器位于 `crates/adapter-*`。  
**验收要点**：权限变更即时生效、接口失败可追踪、审计日志完整。
