# 售后与服务

## 模块定位
覆盖退换补发、退款、逆向物流与售后质检，实现售后全链路闭环与客户满意度提升。

## 业务对象/单据
- 售后申请单、退货单、换货单、补发单
- 退款单、收货/质检单
- 售后异常与SLA记录

## 功能清单与流程
### 1. 售后申请受理
**适用角色**：售后客服  
**流程**：  
1. 客户提交退货/换货/补发申请。  
2. 系统关联原订单与物流信息。  
3. 售后客服审核并生成售后单。  
**关键规则**：  
- 支持按商品、金额、时效配置退换规则。  
- 高风险订单需升级审核。  
**输出**：售后单与处理任务。  

### 2. 退款审核与资金处理
**适用角色**：售后主管、财务会计  
**流程**：  
1. 售后单审核通过后进入退款流程。  
2. 财务确认退款方式与金额。  
3. 退款结果回写订单与客户账户。  
**关键规则**：  
- 支持部分退款与差额退款。  
- 退款需关联原支付单据。  
**输出**：退款凭证与核销记录。  

### 3. 退货收货与质检
**适用角色**：收货员、质检员  
**流程**：  
1. 退货到仓后扫码收货。  
2. 质检判定良品/次品/报废。  
3. 生成入库或报废处理单。  
**关键规则**：  
- 支持批次/序列号追溯。  
- 质检结果影响退款金额。  
**输出**：退货质检报告。  

### 4. 退款拦截物流
**适用角色**：售后客服、物流客服  
**流程**：  
1. 退款申请触发拦截规则判断。  
2. 对已发货订单发起物流拦截。  
3. 拦截结果回写售后单与库存。  
**关键规则**：  
- 支持按承运商配置拦截接口。  
- 拦截失败需自动升级处理。  
**输出**：拦截结果与异常记录。  

### 5. 换货/补发处理
**适用角色**：售后客服、仓储主管  
**流程**：  
1. 生成补发或换货出库指令。  
2. 仓库按售后单进行拣货复核。  
3. 发货后回写售后状态。  
**关键规则**：  
- 支持不同仓库发出换货。  
- 补发可选择原订单或新订单关联。  
**输出**：补发/换货出库记录。  

### 6. 售后库存处理
**适用角色**：仓储主管、财务会计  
**流程**：  
1. 按质检结果设置库存归类。  
2. 良品入可售库存，次品入不良库。  
3. 报废品进入报废审批与成本处理。  
**关键规则**：  
- 不良品库存需单独统计。  
- 报废需关联责任与审批记录。  
**输出**：售后库存台账。  

### 7. 批量编辑售后货品
**适用角色**：售后客服  
**流程**：  
1. 批量导入售后单货品明细。  
2. 系统校验SKU、数量与可退规则。  
3. 批量确认后生成售后单。  
**关键规则**：  
- 支持批量拆分与合并。  
- 异常项需提示并保留修正记录。  
**输出**：批量售后单与校验日志。  

### 8. 售后SLA与事件提醒
**适用角色**：售后主管  
**流程**：  
1. 配置不同售后类型的SLA时效。  
2. 超时自动触发提醒与升级。  
3. 统计SLA达成率与责任归因。  
**关键规则**：  
- 提醒可通过站内信/企业IM机器人推送。  
- SLA变更需记录版本。  
**输出**：SLA达成报告。  

## 对齐与边界说明
**模块边界**：覆盖退货/换货/补发与退款闭环，不包含平台仲裁或维修工厂排程。  
**输入**：平台售后事件、客户申请、物流拦截结果。  
**输出**：售后单、退款/补发指令、退货质检与库存调整。  
**数据对齐**：售后聚合参考 `docs/spec/aftersales_case_schema.md` 与 `docs/spec/05_after_sale_case_aggregation.md`。  
**验收要点**：退货入库一致、退款闭环、拦截失败升级处理。
