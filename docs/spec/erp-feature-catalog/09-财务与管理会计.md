# 财务与管理会计

## 模块定位
覆盖应收应付、费用归集、成本核算与利润分析，打通业务与财务的数据闭环。

## 业务对象/单据
- 应收/应付单、收款/付款单
- 费用单、成本分摊单
- 利润表、成本报表

## 功能清单与流程
### 1. 应收管理与核销
**适用角色**：财务会计  
**流程**：  
1. 销售订单完成后生成应收款。  
2. 按渠道结算周期生成对账单。  
3. 收款后进行核销并更新余额。  
**关键规则**：  
- 支持预收款、分期收款。  
- 核销需关联订单与发票。  
**输出**：应收账龄与核销记录。  

### 2. 应付管理与付款计划
**适用角色**：财务会计  
**流程**：  
1. 采购对账完成后生成应付款。  
2. 根据账期与资金计划生成付款计划。  
3. 付款完成后核销应付款。  
**关键规则**：  
- 支持预付款与冲抵处理。  
- 供应商付款需审批流。  
**输出**：应付账龄与付款记录。  

### 3. 销售费用与营销费用归集
**适用角色**：财务会计、营销主管  
**流程**：  
1. 录入销售费用单与推广费用。  
2. 按货品/订单/渠道规则分摊成本。  
3. 分摊结果回写利润报表。  
**关键规则**：  
- 支持多维分摊策略（金额/销量/权重）。  
- 分摊规则变更需版本管理。  
**输出**：费用分摊明细。  

### 4. 成本核算与库存成本
**适用角色**：财务会计、成本会计  
**流程**：  
1. 汇总采购成本、物流成本、仓储成本。  
2. 计算库存结存成本与出库成本。  
3. 生成成本结转与差异分析。  
**关键规则**：  
- 支持移动平均/先进先出等方法。  
- 成本调整需审批与审计。  
**输出**：成本核算报表。  

### 5. 利润报表与自定义成本
**适用角色**：管理层、财务会计  
**流程**：  
1. 选择利润口径与成本归集规则。  
2. 设置自定义成本项与归集范围。  
3. 生成利润报表并输出多维分析。  
**关键规则**：  
- 支持按店铺/品类/项目维度统计。  
- 报表口径变更需保留版本。  
**输出**：利润报表与口径说明。  

### 6. 代销结算管理
**适用角色**：财务会计、销售主管  
**流程**：  
1. 按代销协议汇总销售明细。  
2. 生成代销对账与结算单。  
3. 结算完成后更新应收与库存。  
**关键规则**：  
- 支持代销扣点与返利规则。  
- 代销库存需单独核算。  
**输出**：代销结算单与核销记录。  

### 7. 税务与发票管理
**适用角色**：财务会计  
**流程**：  
1. 维护税率、税码与发票类型。  
2. 按订单/对账单生成开票记录。  
3. 开票结果回写应收与客户。  
**关键规则**：  
- 支持红冲、作废与重开。  
- 税率变更需生效日期控制。  
**输出**：税务台账与发票记录。  

## 对齐与边界说明
**模块边界**：覆盖应收应付、费用归集、成本与利润分析，不包含总账、税务申报或预算系统。  
**输入**：销售结算、采购对账、物流费用、售后退款与费用单。  
**输出**：应收/应付台账、费用分摊、利润报表、税务与发票记录。  
**协同模块**：销售结算来自 OMS，采购对账来自采购模块，库存成本来自仓储库存模块。  
**验收要点**：对账后核销、退款红冲、成本与利润口径一致。
