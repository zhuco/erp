# 仓储与库存（WMS）

## 模块定位
保障入库、上架、拣货、复核、出库、盘点等仓储作业高效准确，并实现库存实时可视与控制。

## 业务对象/单据
- 入库单、上架单、拣货单、复核单、出库单
- 盘点单、调拨单、移库单
- 批次/序列号、库位与库存台账

## 功能清单与流程
### 1. 入库与上架
**适用角色**：收货员、理货员  
**流程**：  
1. 接收采购/退货/调拨入库指令。  
2. 扫码验收并核对数量与批次。  
3. 按库位策略完成上架并更新库存。  
**关键规则**：  
- 支持多单位入库与自动换算。  
- 支持质检后上架或暂存区规则。  
**输出**：入库确认与库存更新。  

### 2. 库位与货位管理
**适用角色**：仓储主管  
**流程**：  
1. 维护库区、库位、货架与容积信息。  
2. 设定上架规则（FIFO/FEFO/同批次）。  
3. 定期优化库位占用率。  
**关键规则**：  
- 支持温区、危品、专库限制。  
- 支持库位锁定与冻结。  
**输出**：库位策略与占用率报表。  

### 3. 波次拣货与配货
**适用角色**：配货员、仓储主管  
**流程**：  
1. 按订单属性生成拣货波次。  
2. 系统下发拣货路径与任务。  
3. 拣货完成后进入复核/打包。  
**关键规则**：  
- 支持单件拣、批量拣、分区拣。  
- 支持缺货自动转为异常处理。  
**输出**：拣货完成记录。  

### 4. 复核与打包
**适用角色**：验货员、打包员  
**流程**：  
1. 复核SKU、数量与订单信息。  
2. 生成包裹与包装材消耗记录。  
3. 完成称重并回写物流系统。  
**关键规则**：  
- 支持多包裹拆分与合并。  
- 复核差异需自动锁定订单。  
**输出**：复核结果与包裹信息。  

### 5. 出库与发货交接
**适用角色**：打包员、仓库客服  
**流程**：  
1. 获取运单号并打印面单。  
2. 交接给承运商并确认揽收。  
3. 出库完成后释放库存预占。  
**关键规则**：  
- 支持自提/门店调拨出库。  
- 支持异常出库回滚。  
**输出**：出库记录与物流状态。  

### 6. 盘点与差异处理
**适用角色**：仓储主管、盘点员  
**流程**：  
1. 生成盘点计划与盘点范围。  
2. 现场扫码盘点并记录差异。  
3. 差异审批后调整库存。  
**关键规则**：  
- 支持循环盘点与全盘盘点。  
- 差异原因需分类归档。  
**输出**：盘点报告与库存调整单。  

### 7. 库存调拨与移库
**适用角色**：仓储主管  
**流程**：  
1. 生成调拨/移库需求与审批。  
2. 执行出库与入库任务。  
3. 完成后同步库存台账。  
**关键规则**：  
- 支持在途库存管理。  
- 调拨需关联成本转移。  
**输出**：调拨完成记录。  

### 8. 批次与序列号管理
**适用角色**：仓储主管、质检员  
**流程**：  
1. 入库时采集批次/序列号。  
2. 出库按规则选择批次（FIFO/FEFO）。  
3. 异常召回时可追溯批次流向。  
**关键规则**：  
- 支持批次保质期与预警。  
- 序列号需唯一且不可重复入库。  
**输出**：批次追溯与保质期提醒。  

### 9. 库存预警与安全库存
**适用角色**：仓储主管、计划专员  
**流程**：  
1. 设置安全库存与周转天数。  
2. 触发预警后生成补货建议。  
3. 预警记录回写计划模块。  
**关键规则**：  
- 支持按仓库/品类设定阈值。  
- 预警需区分缺货与滞销。  
**输出**：库存预警清单。 

### 10. 入库链路状态机（收货→质检→上架）
**状态建议**：`CREATED/EXPECTED` → `RECEIVING` → `QC_PENDING` → `PUTAWAY_PENDING` → `COMPLETED` / `CANCELLED`。  
**节点说明**：  
1. 上游生成入库指令（采购/退货/调拨/调整）。  
2. 收货扫码记录批次/序列号，进入质检。  
3. 质检合格上架更新库存，不合格进入不良品/退货处理单。  
**台账联动**（参见 `docs/spec/inventory_schema.md`）：  
- 采购入库：`inventory_ledgers.kind=ADJUST`（如需区分可扩展采购入库类型）。  
- 退货入库：`inventory_ledgers.kind=RETURN`。  
- 调拨入库：`inventory_ledgers.kind=TRANSFER_IN`。  
- `ref_type/ref_id` 记录来源单据，确保可追溯。  

### 11. 出库链路状态机（拣货→复核→发货）
**状态建议**：`CREATED` → `ALLOCATED` → `PICKING` → `PICKED` → `PACKING` → `SHIPPED` / `CANCELLED`。  
**节点说明**：  
1. 订单审单后生成出库指令并创建 `inventory_reservations`。  
2. 拣货完成进入复核/打包，打包完成后交接承运商。  
3. 出库完成写入 `inventory_ledgers(SHIP)` 并释放预占。  
4. 取消或拦截发货需释放预占并记录异常原因。  
**台账联动**：  
- 预占：`inventory_ledgers.kind=RESERVE`。  
- 释放：`inventory_ledgers.kind=RELEASE`。  
- 发货：`inventory_ledgers.kind=SHIP`。  

### 12. 库存台账与一致性规则
- 可用库存 = `on_hand - reserved`（不落库，按需计算）。  
- `inventory_reservations` 以 `order_item_id` 唯一，避免重复锁库。  
- 所有库存变动必须记录 `inventory_ledgers` 并关联业务单据。  

### 13. 出入库链路测试清单
- 采购入库：分批到货、部分质检不合格。  
- 退货入库：售后退货与原订单关联。  
- 调拨：调出/调入一致、在途库存可追踪。  
- 出库拣货：缺货转异常、复核差异锁单。  
- 取消订单：释放预占与库存一致。  
### 14. 出入库链路与上游来源对齐
**入库来源**：采购入库、售后退货入库、调拨入库、盘点差异入库。  
**出库来源**：销售出库、售后补发/换货出库、调拨出库、采购退货出库。  
**单据驱动**：所有入/出库均以业务单据为来源，需保留 `ref_type/ref_id` 便于追溯。  

### 15. 库存数据落地与幂等要求
**模型对齐**：`docs/spec/inventory_schema.md` 规定 `inventory_balances`、`inventory_ledgers`、`inventory_reservations`。  
**幂等规则**：  
- 预占以 `order_item_id` 唯一，重复请求不得生成新锁库。  
- 台账记录必须携带来源单据，重复落账需可识别并阻断。  
**可用库存**：`on_hand - reserved`，不落库、按需计算。  

### 16. WMS 与 OMS 协同边界
- OMS 负责审单、拆合单与库存占用决策。  
- WMS 负责执行入库/拣货/复核/出库，并回写执行结果。  
- 订单主状态映射仍以平台为准，WMS 仅反馈履约节点与物流信息。  

## 对齐与边界说明
**模块边界**：仓储模块负责仓内作业与库存台账，不负责订单价格、客户服务或运单管理。  
**输入**：入库指令（采购/退货/调拨）、出库指令（销售/补发/调拨）。  
**输出**：库存台账、履约节点、异常与盘点结果。  
**验收要点**：预占/释放一致、库存不为负、出入库可追溯。
