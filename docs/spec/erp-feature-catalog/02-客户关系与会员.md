# 客户关系与会员（CRM）

## 模块定位
构建统一客户画像与会员体系，支撑全渠道客户识别、客户服务与复购运营。

## 业务对象/单据
- 客户主档、联系人、客户标签
- 会员等级、积分账户、储值账户
- 客服工单、客户满意度记录

## 功能清单与流程
### 1. 客户档案与统一身份
**适用角色**：客户运营专员、系统管理员  
**流程**：  
1. 对接外部平台订单与线下渠道客户数据。  
2. 按手机号、证件号、会员号进行合并去重。  
3. 生成统一客户ID并维护历史变更记录。  
**关键规则**：  
- 支持“公域订单归并”到统一客户档案。  
- 支持客户合并/拆分审批。  
**输出**：客户主档与身份映射表。  

### 2. 会员等级与权益
**适用角色**：客户运营主管  
**流程**：  
1. 配置会员等级、升级条件与权益模板。  
2. 按消费额、订单数、积分自动升级/降级。  
3. 权益发放并同步至订单与营销系统。  
**关键规则**：  
- 支持不同渠道的权益差异化。  
- 等级变更需记录生效时间与原因。  
**输出**：会员等级与权益明细。  

### 3. 积分/储值管理
**适用角色**：客户运营专员、财务会计  
**流程**：  
1. 订单完成后自动累积积分与储值余额。  
2. 退货/退款触发积分回滚或扣减。  
3. 积分兑换或储值抵扣实时回写订单。  
**关键规则**：  
- 积分有效期与冻结期可配置。  
- 储值需与财务应收核销关联。  
**输出**：积分流水与储值账本。  

### 4. 客户标签与分群
**适用角色**：客户运营专员  
**流程**：  
1. 配置标签规则（消费频次、品类偏好、退货率）。  
2. 生成动态分群并支持手动调整。  
3. 分群结果回写营销活动与客服列表。  
**关键规则**：  
- 标签变更需留存版本快照。  
- 支持静态分群锁定。  
**输出**：客户分群名单。  

### 5. 客户生命周期运营
**适用角色**：客户运营主管  
**流程**：  
1. 定义新客、活跃、沉默、流失等阶段。  
2. 为不同阶段配置触达策略与提醒任务。  
3. 触达结果回写客户画像。  
**关键规则**：  
- 支持多渠道触达记录整合。  
- 触达失败需自动生成复联任务。  
**输出**：生命周期状态与运营任务。  

### 6. 客户服务与售后联动
**适用角色**：客户运营专员、售后客服  
**流程**：  
1. 客户咨询/投诉进入客服工单。  
2. 自动关联订单、售后单与物流信息。  
3. 处理结果同步到客户画像与满意度。  
**关键规则**：  
- 工单分派支持技能组与优先级。  
- 超时未处理触发升级提醒。  
**输出**：工单闭环与满意度评分。  

## 对齐与边界说明
**模块边界**：仅覆盖客户主档、会员、积分/储值与客服工单联动，不包含营销自动化、广告投放或外呼系统。  
**输入**：订单/售后数据、渠道注册信息、人工导入客户资料。  
**输出**：客户主档、标签分群、会员等级与积分流水、工单记录。  
**协同模块**：优惠券/活动在营销模块，退款与退货在售后模块。  
**验收要点**：订单识别合并客户、退款触发积分回滚、会员等级自动升级。
