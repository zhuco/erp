# 接口、任务与监控（运行保障）
> 目标：保证跨系统链路稳定、失败可补偿、数据可追溯。

## 1. 接口清单（建议）
| 接口域 | 典型接口 | 方向 | 关键控制点 |
| --- | --- | --- | --- |
| 平台订单 | 拉单/订单查询 | 平台 → ERP | 幂等去重、增量拉取、补拉机制 |
| 平台履约 | 回写发货/取消/退款 | ERP → 平台 | 回写结果落库、失败重试 |
| 仓库对接 | 下发出库/入库；回传出库确认 | ERP ↔ WMS | 签名鉴权、状态一致性 |
| 物流面单 | 获取面单/运单号、轨迹查询 | ERP/WMS ↔ 承运商 | 限流、作废记录 |
| 财务结算 | 回款流水、账单导入 | 平台/银行 → ERP | 对账周期、自动认领 |

## 2. 任务调度与队列
- 定时任务：拉单、波次生成、库存同步、账单导入、超时升级。
- 异步队列：推单WMS、回写平台、面单获取、退款请求。
- 任务幂等：每个任务必须有唯一key与去重策略，避免重复单据。

## 3. 失败处理与补偿
- 重试策略：指数退避 + 最大重试次数 + 失败原因记录。
- 死信队列：超限失败进入DLQ，人工处理后可重放。
- 补偿动作：释放占用、作废包裹、冲销退款、回滚状态。

## 4. 监控指标与告警
- 接口：成功率、失败率、平均耗时、超时率、限流次数。
- 任务：队列积压、重试次数、死信队列数量。
- 业务SLA：拉单→下发时长、下发→出库时长、售后受理→退款时长。
- 库存异常：负库存、可用库存为负、账实差异超阈值。

## 5. 系统自检与对账
- 订单对账：平台订单状态 vs ERP订单状态。
- 库存对账：WMS库存 vs ERP库存台账；库位合计=仓库库存。
- 结算对账：平台账单 vs ERP结算明细；退款金额与售后单一致。
