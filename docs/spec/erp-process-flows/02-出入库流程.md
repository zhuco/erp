# 出入库流程（待开发完善）
> 覆盖入库（采购/退货/调拨）与出库（销售/调拨/退供）的作业链路。

## 1. 目标与范围
- 统一入库、出库的单据、状态与操作节点，保证库存账实一致。
- 支撑波次、拣货、复核、包装与发运等WMS动作。

## 2. 关键角色
- 收货员、质检员、上架员、拣货员、复核员、仓库主管。

## 3. 单据与数据对象
- 入库单、收货记录、质检记录、上架单、出库单、波次、拣货任务、复核记录、装箱单、包裹/发货单。
- 关联主数据：仓库/库区/库位、SKU、批次/效期、容器、承运商。

### 3.1 子单据与勾稽关系（建议）
- 入库：ASN/入库单 → 收货记录（RC） → 质检单（QC） → 上架任务（PT） → 入库确认（GR）。
- 出库：出库单（OB） → 波次（WAVE） → 拣货任务（PK） → 复核打包单（PA） → 包裹/发货单（PKG） → 交接单（HO）。

## 4. 状态定义
### 4.1 入库单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建入库单 | 提交审核 |
| 待审核 | 等待审核 | 提交审核 | 审核通过/驳回 |
| 待收货 | 允许收货 | 审核通过 | 开始收货 |
| 收货中 | 收货进行中 | 扫描到货 | 收货完成 |
| 待质检 | 等待质检 | 收货完成 | 质检通过/不通过 |
| 待上架 | 等待上架 | 质检通过 | 开始上架 |
| 上架中 | 上架作业中 | 上架任务下发 | 上架完成 |
| 已完成 | 入库闭环 | 上架完成 | - |
| 已关闭 | 作废/取消 | 手工关闭 | - |

| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建出库单 | 提交审核 |
| 待审核 | 等待审核 | 提交审核 | 审核通过/驳回 |
| 待分配 | 等待波次/拣货分配 | 审核通过 | 分配完成 |
| 待拣货 | 等待拣货 | 分配完成 | 拣货开始 |
| 拣货中 | 拣货进行中 | 拣货任务执行 | 拣货完成 |
| 待复核 | 等待复核 | 拣货完成 | 复核通过/异常 |
| 待打包 | 等待打包 | 复核通过 | 打包完成 |
| 待发运 | 等待交运 | 打包完成 | 出库完成 |
| 已出库 | 出库完成 | 交接物流 | - |
| 已关闭 | 取消/作废 | 手工关闭 | - |

| 状态 | 含义 | 进入条件 | 退出条件 | 建议枚举 |
| --- | --- | --- | --- | --- |

| 状态 | 含义 | 进入条件 | 退出条件 | 建议枚举 |
| --- | --- | --- | --- | --- |
| 未发货 | 包裹未交运 | 包裹生成 | 发货开始 | `NOT_SHIPPED` |

| 发货失败 | 交运失败 | 交运失败 | 重试/作废 | `SHIP_FAILED` |

## 5. 标准流程（含状态流转与影响）
### 5.1 入库流程
1. 入库单创建与审核
   - 状态：草稿 → 待审核 → 待收货
   - 影响：生成收货计划；锁定采购/退货数量。
2. 收货与质检
   - 状态：待收货 → 收货中 → 待质检
   - 影响：生成收货差异记录；决定可入库数量。
3. 上架与完成
   - 状态：待上架 → 上架中 → 已完成
   - 影响：库存增加；库位占用更新；触发成本入账。

### 5.2 出库流程
1. 出库单创建与审核
   - 状态：草稿 → 待审核 → 待分配
   - 影响：冻结库存；等待波次生成。
2. 波次生成与下发
   - 状态：待分配 → 待拣货
   - 影响：生成波次、下发拣货任务。
3. 拣货与复核
   - 状态：待拣货 → 拣货中 → 待复核
   - 影响：拣货扣减可用库存；复核差异记录。
4. 打包与发运
   - 状态：待打包 → 待发运 → 已出库
   - 影响：生成装箱单、包裹/发货单与物流单号；出库后库存实扣。

## 6. 波次策略与分配方式（建议）
- 先波后分：先按规则组波，再分配库存，适合多仓、多承运商场景。
- 先分后波：先锁定库存，再组波拣货，适合库存紧张或单品集中场景。
- 波次维度：仓库、库区、承运商、订单类型、时效要求、重量体积。
- 限定条件：波次内订单数/件数上限、最大等待时间、是否允许跨区拣货。

## 7. 回退与补偿动作（示例）
- 取消波次：释放分配库存，回退至“待分配”。
- 拣货回退：生成归还上架/移库任务，恢复拣货前状态。
- 打包作废：作废包裹单与面单号，回退至“待打包”。
- 入库回退：已收货需生成调整/冲销单，禁止直接作废。

## 8. 异常处理与退回上级
- 收货短/多/损：退回仓库主管确认；可生成补收/退货单。
- 批次/效期不符：退回质检或采购；允许拒收并记录原因。
- 拣货差异：退回复核并重新拣货；必要时锁定库位复盘。
- 无库位/库位满：退回上架环节，触发库位调整或移库。

## 9. 操作影响清单
- 库存：入库增加可用量；出库扣减并影响可售库存。
- 订单：出库完成同步订单履约与物流状态。
- 财务：入库产生成本入账；出库影响毛利与费用分摊。
- 绩效：收货、拣货、复核等记录用于绩效考核。
