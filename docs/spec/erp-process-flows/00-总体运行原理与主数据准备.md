# 总体运行原理与主数据准备（V1上线必读）
> 目标：统一术语、边界与主数据口径，确保流程可落地、可验收。

## 1. 适用范围与目标
- 覆盖全渠道订单、仓储履约、采购入库、结算与售后闭环。
- 作为产品、研发、实施、运营、仓库、财务的共同对齐文档。

## 2. 总体运行逻辑
- 三流一致：信息流（单据与状态）、物流（实物出入库与运输）、资金流（收付款与对账）。
- 端到端闭环：O2C（Order-to-Cash）与 P2P（Procure-to-Pay）。
- 单据驱动：上游单据生成下游单据，状态变化触发库存、财务、平台回写。

## 3. 模块分层与职责边界（建议）
| 层级 | 模块 | 核心职责 | 典型输出 |
| --- | --- | --- | --- |
| 主数据层 | PIM/MDM | 商品、仓库、店铺、供应商、物流、税率、成本口径 | SKU/条码/规格/成本、渠道映射 |
| 业务中台层 | OMS | 订单拉取、审单、分仓、拆合单、库存预占、下发WMS | 销售订单、履约子单 |
| 执行层 | WMS | 入库、上架、拣货、复核、打包、出库、盘点 | 入库单/出库单/包裹单 |
| 供应链层 | SCM | 采购申请、采购订单、到货与退货 | 采购申请/采购订单 |
| 财务层 | FMS | 对账、核销、结算、退款冲销 | 对账单/结算单/核销记录 |

## 4. 单据驱动与勾稽关系
- 通过 `source_id`、`source_type`、`source_line_id` 保留单据来源与追溯关系。
- 正向链路示例：平台订单 → 销售订单 → 出库需求 → 波次 → 拣货 → 复核打包 → 包裹 → 出库确认 → 结算明细。
- 逆向链路示例：售后申请 → 退货单 → 退货入库 → 质检 → 退款冲销 → 结算调整。

## 5. 单据编号规范（建议）
| 单据 | 编码示例 | 说明 |
| --- | --- | --- |
| 销售订单 | SO{yyyyMMdd}{seq} | 订单主单据 |
| 履约子单/发货单 | SH{yyyyMMdd}{seq} | 分仓/拆合单后生成 |
| 出库单 | OB{yyyyMMdd}{seq} | 下发WMS执行 |
| 入库单 | IB{yyyyMMdd}{seq} | 采购/退货/调拨入库 |
| 采购申请 | PR{yyyyMMdd}{seq} | 需求发起 |
| 采购订单 | PO{yyyyMMdd}{seq} | 供应商确认 |
| 售后单 | RMA{yyyyMMdd}{seq} | 退货/换货/补发 |
| 对账/结算 | ST/JS{yyyyMMdd}{seq} | 账期对账 |

## 6. 主数据上线清单（V1必备）
### 6.1 组织/仓库/库位
- 仓库编码、类型、自营/三方仓、库区、库位属性（可拣/可上架/可盘点/冻结）。

### 6.2 店铺/渠道/授权
- 店铺授权凭证、拉单范围、回写能力、面单方式、退货地址、结算主体。
- 渠道能力矩阵：是否支持自动回写、拦截、账单明细。

### 6.3 商品主数据
- SKU唯一编码、条码、规格、单位、重量/体积、税率、成本口径、批次/效期规则。
- 渠道SKU映射：缺失映射的订单进入问题件队列。

### 6.4 供应商与采购条款
- 供应商编码、结算方式、账期、税率、开票信息、默认收货仓。

### 6.5 物流与面单
- 承运商、服务产品、计费规则、禁运规则、面单模板。

### 6.6 财务基础资料
- 结算主体、税率、发票类型、收付款账户、费用科目、结算周期。

## 7. 库存口径与关键公式
| 口径 | 含义 |
| --- | --- |
| 现有库存（On Hand） | 实际在库数量 |
| 可用库存（Available） | 现有 - 预占 - 锁定 - 冻结 - 待检 |
| 预占库存（Reserved） | 审单或分配阶段占用 |
| 锁定库存（Locked） | 出库单已创建 |
| 在途库存（In Transit） | 调拨/采购在途 |
| 冻结库存（Frozen） | 盘点/异常冻结 |

## 8. 幂等、重试与补偿（关键原则）
- 幂等：下游接口必须以幂等键去重，重复请求返回同一结果。
- 重试：超时/限流可重试，参数错误不可重试；记录重试次数与结果。
- 补偿：跨系统不一致时，用补偿单据/事件修正，禁止手工改数。
