# 售后服务流程（待开发完善）
> 覆盖退款、退货、换货、补发等售后闭环。

## 1. 目标与范围
- 统一售后申请、受理、退货、退款、换货的流程与状态。
- 与订单、库存、结算联动，降低售后成本并提升客户体验。

## 2. 关键角色
- 客服专员、售后主管、质检员、仓库主管、财务。

## 3. 单据与数据对象
- 售后申请单、退货单、退款单、换货单、补发单、售后工单。
- 关联数据：订单、物流、客户、售后原因、赔付规则。

## 4. 状态定义
### 4.1 售后申请状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 已提交 | 客户提交申请 | 售后申请创建 | 审核通过/驳回 |
| 待审核 | 等待审核 | 提交申请 | 受理/驳回 |
| 已受理 | 确认处理 | 审核通过 | 进入退款/退货/换货 |
| 已驳回 | 不符合规则 | 审核拒绝 | 重新申请/关闭 |
| 已关闭 | 售后结束 | 完成或取消 | - |

### 4.2 退货单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待寄回 | 等待客户寄回 | 受理退货 | 客户寄回 |
| 在途 | 退货运输中 | 物流回传 | 到货签收 |
| 待收货 | 等待仓库收货 | 物流到仓 | 收货完成 |
| 质检中 | 质检处理 | 收货完成 | 质检通过/不通过 |
| 质检通过 | 可入库 | 质检通过 | 入库完成 |
| 质检不通过 | 不可入库 | 质检失败 | 争议处理 |

### 4.3 退款单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待审核 | 等待退款审批 | 申请通过 | 退款执行 |
| 待退款 | 等待打款 | 审批通过 | 退款成功/失败 |
| 已退款 | 退款完成 | 退款成功 | - |
| 退款失败 | 退款异常 | 退款失败 | 重试/关闭 |

### 4.4 换货/补发状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待出库 | 等待出库 | 换货/补发受理 | 出库完成 |
| 出库中 | 拣货打包 | 出库任务执行 | 发货完成 |
| 已发出 | 已发货 | 发货完成 | 签收完成 |
| 已完成 | 售后结案 | 签收完成 | - |

## 5. 标准流程（含状态流转与影响）
1. 售后申请与受理
   - 状态：已提交 → 待审核 → 已受理/已驳回
   - 影响：生成售后工单；锁定售后责任人。
2. 退货处理（如适用）
   - 状态：待寄回 → 在途 → 待收货 → 质检中
   - 影响：形成退货物流与质检记录；决定可入库数量。
3. 退款/换货执行
   - 状态：待审核 → 待退款 → 已退款 或 待出库 → 已发出
   - 影响：库存回补或报损；资金退回或补发出库。
4. 结案与回访
   - 状态：已完成/已关闭
   - 影响：更新订单售后状态；生成售后满意度记录。

## 6. 售后类型与触发来源
- 售后类型：仅退款、退货退款、换货、补发、维修。
- 触发来源：客户申请、平台判责、客服主动发起、物流异常。

## 7. 举证与赔付规则
- 举证材料：商品照片/视频、物流轨迹、签收证明、客服记录。
- 赔付策略：金额阈值审批、责任归属（商家/仓库/物流/平台）。
- 赔付结果需回写售后单与财务费用科目。

## 8. 异常处理与退回上级
- 超时未寄回：退回售后主管确认是否关闭或延长。
- 退货物料缺失/损坏：升级主管处理赔付或拒收。
- 退款失败：退回财务复核并触发重试或人工打款。
- 争议订单：升级客服主管决策，形成平台举证记录。

## 9. 操作影响清单
- 库存：合格退货入库，不合格进入不良或报损。
- 财务：退款影响现金流与利润；赔付计入费用。
- 客户体验：影响复购与评价，需要SLA跟踪。
