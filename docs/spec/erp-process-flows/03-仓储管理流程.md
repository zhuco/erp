# 仓储管理流程（待开发完善）
> 覆盖仓库基础、库存状态、盘点、调拨、调整与补货策略。

## 1. 目标与范围
- 保证库存账实一致，支持多仓、多库区、多库位管理。
- 对库存状态、盘点、调拨与调整形成可追溯流程。

## 2. 关键角色
- 仓库管理员、库存主管、盘点员、仓库主管。

## 3. 单据与主数据
- 仓库、库区、库位、容器、批次、序列号、库存台账。
- 库存单据：盘点单、库存调整单、移库单、调拨单、补货任务。

## 4. 状态定义
### 4.1 库存状态
| 状态 | 含义 | 触发场景 |
| --- | --- | --- |
| 可用 | 可被分配与出库 | 入库上架完成 |
| 预占 | 订单占用但未锁定 | 审核通过待分配 |
| 锁定 | 已分配待出库 | 出库单生成 |
| 冻结 | 暂不可用 | 盘点/异常处理 |
| 待检 | 等待质检 | 收货后 |
| 不良 | 需报损或返修 | 质检失败 |
| 在途 | 调拨运输中 | 调拨单发出 |

### 4.2 盘点单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建盘点单 | 提交审批 |
| 待盘点 | 等待盘点 | 审批通过 | 盘点开始 |
| 盘点中 | 盘点执行中 | 盘点任务下发 | 盘点完成 |
| 待复核 | 等待复核 | 盘点完成 | 复核通过/驳回 |
| 已完成 | 盘点结案 | 复核通过 | - |
| 已关闭 | 盘点取消 | 手工关闭 | - |

### 4.3 调拨/移库单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建单据 | 提交审核 |
| 待出库 | 等待发出 | 审核通过 | 出库完成 |
| 在途 | 已发出 | 出库完成 | 到货确认 |
| 已完成 | 入库完成 | 到货确认 | - |
| 已关闭 | 取消/作废 | 手工关闭 | - |

## 5. 标准流程（含状态流转与影响）
1. 仓库基础设置
   - 影响：决定库位容量、拣选策略与库存归属。
2. 库存状态管理
   - 影响：预占、锁定、冻结直接影响可售与拣货。
3. 库存盘点
   - 状态：待盘点 → 盘点中 → 待复核 → 已完成
   - 影响：冻结库位库存；盘盈盘亏写入库存调整单。
4. 库存调整
   - 影响：报损/报溢进入财务成本；需要主管审批。
5. 调拨与移库
   - 影响：库存从源仓转为在途，再回到目标仓可用量。
6. 补货与上架策略
   - 影响：提高拣货效率，减少缺货与跨区作业。

## 6. 补货与移库策略（建议）
- 补货触发：拣货区库存低于阈值、波次集中拣货、热销SKU。
- 移库策略：按库位容量、批次/效期规则、路径最短优先。
- 关键控制：补货/移库必须可追溯，避免账实不一致。

## 7. 库存调整与冻结/解冻
- 调整类型：报损、报溢、盘盈盘亏、临时冻结。
- 调整流程：申请 → 审批 → 调整入账 → 审计记录。
- 冻结/解冻：需记录原因码与责任人，支持超时自动提醒。

## 8. 仓储报表与KPI建议
- 出库：波次完成时长、拣货效率、复核差错率、交接准时率。
- 入库：到货处理时长、质检不合格率、上架及时率。
- 库存：账实差异率、库龄结构、周转天数、冻结占比。

## 9. 异常处理与退回上级
- 盘点差异过大：退回复核并升级仓库主管审批。
- 负库存或超容量：退回库存调整，要求重新核对入库/出库单据。
- 调拨在途超时：升级仓储负责人确认运输与库存责任归属。

## 10. 操作影响清单
- 库存准确率、可售库存、缺货预警。
- 仓库绩效与人员效率统计。
- 财务成本与报损报溢记录。
