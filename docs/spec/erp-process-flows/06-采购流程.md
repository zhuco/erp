# 采购流程（待开发完善）
> 覆盖需求提出、审批、下单、收货、质检、入库与供应商结算。

## 1. 目标与范围
- 根据销售/库存预测形成采购闭环，保证供应连续。
- 控制采购审批、收货与质量，确保成本与供应风险可控。

## 2. 关键角色
- 采购专员、采购主管、供应商、质检员、仓库主管、财务。

## 3. 单据与数据对象
- 采购申请、采购订单、到货通知、收货记录、质检记录、退货单。
- 关联主数据：供应商、结算条款、SKU成本、交期、最小起订量。

### 3.1 单据链路与编号规范（建议）
| 单据 | 编码示例 | 来源/说明 |
| --- | --- | --- |
| 采购申请 | PR{yyyyMMdd}{seq} | 需求或补货触发 |
| 采购订单 | PO{yyyyMMdd}{seq} | 采购申请审批通过 |
| 到货通知/ASN | ASN{yyyyMMdd}{seq} | 供应商确认到货 |
| 收货记录 | RC{yyyyMMdd}{seq} | 仓库收货扫描 |
| 质检单 | QC{yyyyMMdd}{seq} | 质检判定 |

## 4. 状态定义
### 4.1 采购申请状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建申请 | 提交审批 |
| 待审批 | 等待审批 | 提交审批 | 批准/驳回 |
| 已批准 | 允许下单 | 审批通过 | 转采购订单 |
| 已驳回 | 未通过 | 审批驳回 | 重新提交/关闭 |
| 已关闭 | 终止申请 | 手工关闭 | - |

### 4.2 采购订单状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 草稿 | 待提交 | 新建订单 | 提交审批 |
| 待审批 | 等待审批 | 提交审批 | 审批通过/驳回 |
| 已下单 | 已通知供应商 | 审批通过 | 部分到货/取消 |
| 部分到货 | 未完全收货 | 首次收货 | 全部到货/关闭 |
| 已到货 | 已完成收货 | 全部收货 | 结案 |
| 已关闭 | 取消或终止 | 手工关闭 | - |

### 4.3 收货与质检状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待收货 | 等待到货 | PO已下单 | 收货开始 |
| 收货中 | 收货执行 | 到货扫描 | 收货完成 |
| 待质检 | 等待质检 | 收货完成 | 质检通过/不通过 |
| 质检通过 | 可入库 | 质检通过 | 入库完成 |
| 质检不通过 | 不合格 | 质检失败 | 退货/让步接收 |

## 5. 标准流程（含状态流转与影响）
1. 需求计划与采购申请
   - 状态：草稿 → 待审批 → 已批准
   - 影响：锁定预算与采购计划；触发供应商选择。
2. 采购订单下达
   - 状态：已批准 → 已下单
   - 影响：生成到货计划；更新在途库存预测。
3. 收货与质检
   - 状态：待收货 → 收货中 → 待质检 → 质检通过
   - 影响：形成收货差异记录；影响可用库存与成本。
4. 入库与结案
   - 状态：质检通过 → 已到货
   - 影响：库存增加；更新采购成本与供应商绩效。
5. 退货与补货
   - 影响：生成退货单或补货单；调整采购订单数量。

## 6. 供应商确认与交期管理
- 供应商确认：确认价格、数量、交期与交付方式。
- 交期预警：超期未确认/未到货自动预警与升级。
- 变更控制：价格或交期变更需重新审批。

## 7. 采购对账与应付联动
- 收货/质检完成后生成应付明细或对账明细。
- 采购退货需冲销应付或生成差异单。

## 8. 异常处理与退回上级
- 价格或交期变更：退回采购主管审批或重新谈判。
- 到货短缺/破损：退回收货与质检环节，要求供应商补发。
- 质检不通过：升级质量负责人，决定退货或让步接收。

## 9. 操作影响清单
- 库存：在途、可用库存与安全库存预警。
- 财务：采购成本、付款计划与预算占用。
- 供应链：供应商绩效、交期与质量评分。
