# 订单处理流程（待开发完善）
> 覆盖订单拉取/录入、审核、分配、出库、发货、完成的闭环。

## 1. 目标与范围
- 对电商平台订单进行标准化处理，形成可追溯单据与状态。
- 与仓储、物流、结算、售后流程联动，保证库存与账务一致。

## 2. 关键角色
- 订单专员、审核员、客服主管、仓库主管、财务对账员。

## 3. 单据与数据对象
- 销售订单、订单明细、审核记录、异常单、出库单、发货单、物流单号。
- 关联主数据：客户、店铺、仓库、SKU、促销规则、价格政策。

### 3.1 单据链路与编号规范（建议）
| 单据 | 编码示例 | 来源/说明 |
| --- | --- | --- |
| 销售订单 | SO{yyyyMMdd}{seq} | 平台订单标准化后生成 |
| 履约子单/发货单 | SH{yyyyMMdd}{seq} | 分仓/拆合单后生成 |
| 订单异常单 | EX{yyyyMMdd}{seq} | 规则命中或人工标记 |
| 拦截/取消单 | IC{yyyyMMdd}{seq} | 客服/平台发起 |
| 售后单 | RMA{yyyyMMdd}{seq} | 退货/换货/补发 |

## 4. 状态定义
### 4.1 订单主状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 新建/草稿 | 拉单或手工录入 | 订单创建 | 提交审核/取消 |
| 待审核 | 等待自动/人工审核 | 提交审核 | 审核通过/驳回 |
| 审核驳回 | 不满足规则 | 审核拒绝 | 重新提交/关闭 |
| 异常挂起 | 需人工处理 | 命中异常规则 | 放行/退回/关闭 |
| 待分配 | 通过审核等待分仓 | 审核通过 | 已分仓/拆合单 |
| 待出库 | 出库单已创建 | 分配完成 | 开始拣货 |
| 出库中 | 拣货/打包进行中 | 拣货任务下发 | 已发货/取消 |
| 已发货 | 物流信息已回传 | 出库完成 | 签收/退回 |
| 已签收 | 物流确认签收 | 签收回传 | 完成/售后 |
| 已完成 | 订单结案 | 签收且无售后 | - |
| 已取消/关闭 | 订单终止 | 平台取消/手工取消 | - |

### 4.2 审核与履约子状态
- 审核状态：未审核、自动通过、人工审核中、审核通过、审核驳回、退回重审。
- 履约状态：未分配、已分配、拣货中、待打包、待发运、已发货、履约异常。

### 4.3 交易与支付状态字段建议
- `trade_status`：待支付、已支付、已取消、已退款。
- `payment_status`：UNPAID、PAID、PART_REFUNDED、REFUNDED。
- `fulfillment_status` 与 `review_status` 保持独立，避免一个字段承载多语义。

## 5. 标准流程（含状态流转与影响）
1. 订单拉取/录入
   - 状态：新建/草稿 → 待审核
   - 影响：创建订单与审核任务；按策略预占库存；生成审单日志。
2. 自动/人工审核
   - 状态：待审核 → 待分配/审核驳回/异常挂起
   - 影响：放行则锁定库存；驳回或异常则释放预占库存并通知客服。
3. 分仓/拆合单/波次
   - 状态：待分配 → 待出库
   - 影响：生成出库单/波次；冻结库存；计算运费与仓配成本。
4. 出库执行（WMS）
   - 状态：待出库 → 出库中 → 已发货
   - 影响：拣货扣减可用库存；打包后生成物流单号并回传平台。
5. 物流跟踪与签收
   - 状态：已发货 → 已签收
   - 影响：触发结算与售后窗口；形成签收日志。
6. 结案与归档
   - 状态：已签收 → 已完成
   - 影响：关闭订单任务；释放绩效统计；进入利润与对账流程。

## 6. 异常处理与退回上级
- 地址错误/疑似欺诈：进入“异常挂起”，退回主管审核；可选择放行或关闭。
- 缺货/库存不足：退回分仓或审核环节；允许改仓、拆单或补货后重启。
- 物流失败/退回：回退至“待出库”或“异常挂起”；需主管批准再次发货。
- 平台取消/支付失败：自动关闭订单并释放库存，记录取消原因。

### 6.1 取消与拦截按节点规则
| 节点 | 典型状态 | 处理动作 | 库存影响 | 说明 |
| --- | --- | --- | --- | --- |
| 未下发仓库 | 待审核/待分配 | 直接取消 | 释放预占 | 记录取消原因 |
| 已下发未出库 | 待出库/拣货中 | 发起拦截单 | 拦截成功释放 | 超时自动升级 |
| 已发货 | 已发货/已签收 | 转售后流程 | 不回退库存 | 走退货入库 |

### 6.2 异常队列与上级处理机制
- 异常需进入“异常队列/工单”，包含原因码、责任部门、处理时限与审计日志。
- 上级处理通过“审批任务”完成：触发条件→分派审批人→审批结果写回状态。

## 7. 字段锁定规则（示例）
| 字段类别 | 可编辑阶段 | 锁定阶段 | 原因 |
| --- | --- | --- | --- |
| 收件信息 | 待审核/分仓前 | 下发仓库后 | 避免与面单不一致 |
| SKU/数量 | 待审核/拆合单 | 预占完成后 | 避免库存与成本偏差 |
| 价格/优惠 | 待审核 | 审核通过后 | 影响结算口径 |

## 8. 操作影响清单
- 库存：预占 → 锁定 → 扣减/释放，影响可售库存与缺货预警。
- 财务：生成应收、运费成本与毛利估算；签收后进入结算。
- 客户与服务：影响客服工单、售后可申请窗口、评价通知。
- 数据与审计：记录审核/变更日志，形成绩效与风控指标。
