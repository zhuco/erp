# 结算流程（待开发完善）
> 覆盖平台对账、费用核对、发票、回款与结案流程。

## 1. 目标与范围
- 统一平台账单与内部订单、物流、退款数据的核对。
- 形成结算单与回款记录，支撑利润分析。

## 2. 关键角色
- 财务对账员、财务主管、结算专员、运营负责人。

## 3. 单据与数据对象
- 平台对账单、对账任务、差异记录、结算单、发票、回款记录。
- 关联数据：订单、退款、运费、佣金、促销补贴。

## 4. 状态定义
### 4.1 对账任务状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待导入 | 等待账单 | 账期开始 | 账单导入 |
| 已导入 | 账单落库 | 导入成功 | 启动对账 |
| 对账中 | 自动/人工对账 | 启动对账 | 对账完成/异常 |
| 差异处理中 | 存在差异 | 对账发现差异 | 差异关闭 |
| 对账完成 | 完成核对 | 差异关闭 | 生成结算单 |

### 4.2 结算与回款状态
| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 待结算 | 待生成结算单 | 对账完成 | 结算确认 |
| 待开票 | 结算待开票 | 结算确认 | 开票完成 |
| 待回款 | 等待回款 | 发票开具 | 回款确认 |
| 已回款 | 回款完成 | 回款确认 | - |
| 已关闭 | 结算终止 | 手工关闭 | - |

## 5. 标准流程（含状态流转与影响）
1. 账单导入
   - 状态：待导入 → 已导入
   - 影响：形成对账任务与账单明细。
2. 对账匹配
   - 状态：已导入 → 对账中
   - 影响：订单、退款、运费、佣金匹配。
3. 差异处理
   - 状态：对账中 → 差异处理中 → 对账完成
   - 影响：形成差异原因、补单或调整记录。
4. 结算确认
   - 状态：对账完成 → 待结算
   - 影响：生成结算单，锁定账期数据。
5. 开票与回款
   - 状态：待开票 → 待回款 → 已回款
   - 影响：更新应收与现金流，生成发票档案。

## 6. 核销机制与口径（建议）
- 核销对象：对账单、应收明细、收款单之间的匹配关系。
- 核销方式：按单核销、按明细核销、按金额部分核销。
- 口径选择：发货即确认收入 vs 签收确认收入，需在账期统一。

## 7. 差异单与争议处理
- 对账差异形成差异单：原因码、责任部门、处理结论。
- 超阈值差异自动升级审批，禁止直接改账单金额。

## 8. 退款冲销与售后联动
- 仅退款（未发货）：冲销应收，释放占用库存。
- 退货退款（已发货）：退货质检后冲销应收与成本。
- 拒收/拦截退回：按物流回传结果选择退款口径。

## 9. 异常处理与退回上级
- 订单缺失/重复：退回运营复核，必要时补拉平台订单。
- 费用异常：升级财务主管确认费率或补贴规则。
- 回款延迟：退回结算专员，触发催收与风险记录。

## 10. 操作影响清单
- 财务：应收、毛利、费用分摊与资金计划。
- 业务：影响平台结算信誉与订单复核策略。
- 数据：形成结算快照用于报表。
