# 权限、审批与审计
> 目标：让关键动作可控、可追溯、可回退。

## 1. 权限模型（建议）
- RBAC：用户 → 角色 → 权限点（菜单/按钮/字段）。
- 数据范围：按店铺、仓库、部门、区域控制数据可见性。
- 字段权限：成本、价格、地址等敏感字段可分级控制。

## 2. 审批流与上级处理
- 触发条件：金额阈值、强制拦截、强制作废、库存强制释放、超卖放行。
- 审批任务：生成审批单 → 指定审批人 → 审批结果回写状态。
- 退回上级：必须记录原因码、责任人、处理结论与审计日志。

## 3. 字段可编辑与锁定规则
- 订单收件信息：下发仓库前可改，下发后默认锁定。
- SKU/数量：审单与拆合单阶段可改，预占完成后锁定。
- 成本/税率：需财务审批并记录生效日期。

## 4. 审计日志与追溯
- 记录内容：操作人、时间、动作、前后值、原因码。
- 关键动作：审核/反审核、作废、强制出库、库存调整、退款。
- 查询能力：按单据、按人员、按时间范围可追溯。

## 5. 权限与状态机联动
- 状态决定按钮与字段可见性；权限决定是否可执行。
- 状态回退必须经过审批，避免无记录修改历史数据。
