# 后端上线验收清单（V1）
> 用于上线前验收“核心链路可跑、数据可追溯、故障可恢复”。

## 1. 验收范围
- 订单、出入库、仓储、商品、采购、结算、售后等核心链路的后端能力。
- 平台/仓库/物流/财务关键对接的最小可用集成。
- 权限、日志、任务、监控与补偿机制。

## 2. V1必须完成（上线硬门槛）
### 2.1 核心业务接口
- [ ] 订单：拉单/录入、审核、分仓、下发WMS、发货回写、签收、取消/拦截。
- [ ] 出库：出库单、拣货、复核打包、包裹/运单、出库确认。
- [ ] 入库：入库单、收货、质检、上架、入库确认。
- [ ] 仓储：盘点、库存调整、移库/调拨（至少一种）。
- [ ] 商品：SKU主数据、启用/停用、渠道映射。
- [ ] 采购：采购申请、采购订单、收货与退货处理。
- [ ] 结算：账单导入、对账、结算单生成、回款登记。
- [ ] 售后：退款或退货或换货三者至少跑通一条闭环。

### 2.2 状态机与数据一致性
- [ ] 每类单据具备主状态与关键子状态字段。
- [ ] 状态变更触发库存/财务/平台回写的联动可追溯。
- [ ] 关键回退操作有审批/原因码/审计记录。

### 2.3 数据模型与迁移
- [ ] 主数据/业务单据/日志表落库，字段与索引完整。
- [ ] 关键唯一约束（订单号、SKU、幂等键）生效。
- [ ] 数据迁移脚本可回滚/可重复执行。

### 2.4 幂等、重试与补偿
- [ ] 外部接口具备幂等键去重机制。
- [ ] 可重试/不可重试错误分级处理。
- [ ] 失败补偿动作可触发（释放占用、作废包裹、冲销退款）。

### 2.5 任务与队列
- [ ] 拉单、回写、波次、库存同步、对账导入的定时任务。
- [ ] 异步队列具备失败重试与死信队列。
- [ ] 任务状态可查询、可重放。

### 2.6 权限与审计
- [ ] RBAC与数据范围控制生效。
- [ ] 关键按钮（审核/作废/强制释放）有权限控制。
- [ ] 审计日志记录操作人、时间、前后值与原因码。

### 2.7 监控与告警
- [ ] 接口成功率/失败率/超时率指标可观测。
- [ ] 队列积压与死信队列告警可触发。
- [ ] 关键SLA（拉单到下发、下发到出库）有监控。

### 2.8 基础集成（最小可用）
- [ ] 平台拉单与发货回写（至少一平台）。
- [ ] WMS下发与回传（至少一仓）。
- [ ] 物流面单/运单号获取（至少一承运商）。
- [ ] 结算账单导入（至少一平台或模拟数据）。

### 2.9 初始化数据与配置
- [ ] 店铺授权、仓库库区库位、SKU与渠道映射已配置。
- [ ] 供应商、税率、结算主体、费用科目已配置。
- [ ] 规则配置：审单规则、波次规则、库存口径。

## 3. 可延后项（不影响V1上线）
- 智能波次优化、自动装箱、库位推荐。
- 供应商评分与智能寻源。
- 高级核销规则、资金预测、利润分摊模型。
- 售后举证自动化与赔付策略引擎。

## 4. 验收方式（建议）
- **流程回归**：按“订单→出库→发货→对账”全链路走通。
- **异常用例**：缺货、拦截失败、面单失败、对账差异。
- **数据一致性**：库存台账与业务单据可对账。
- **权限验收**：关键动作权限与审计日志完整。
